- **6种终端后端**: local, Docker, SSH, Daytona, Singularity, Modal
- **服务器无持久化**: Daytona和Modal提供服务器无持久化，空闲时成本几乎为零
- **运行成本低**: 可在5美元的VPS或GPU集群上运行

- **跨会话召回**，FTS5会话搜索 + LLM摘要
- **用户建模**，兼容Honcho辩证用户建模

#### 🔧 **技能生态系统**

#### 💬 **多平台通信**

- **语音备忘录转录**

#### ⚙️ **调度自动化**

- **每日报告、夜间备份、每周审计**

## 🔍 详细技术分析

### 1. 记忆系统 (Memory System)

#### 架构设计
```
两个核心文件:
1. MEMORY.md - 代理的个人笔记 (2,200字符限制)
2. USER.md - 用户配置文件 (1,375字符限制)
```

#### 关键特性
- **有界策划记忆**: 保持记忆聚焦，避免无限增长
- **字符限制**: MEMORY.md 2,200字符，USER.md 1,375字符
- **冻结快照模式**: 会话开始时注入系统提示，保持LLM前缀缓存
- **子字符串匹配**: 使用短唯一子字符串进行替换和删除操作

#### 记忆管理
- **自动保存**: 代理自动保存学习到的信息
- **容量管理**: 当记忆满时，代理合并或替换条目
- **目标分类**: memory(环境事实) vs user(用户偏好)

### 2. 技能系统 (Skills System)

#### 技能格式
```yaml
---
name: my-skill
description: Brief description of what this skill does
version: 1.0.0
platforms: [macos, linux]
metadata:
  hermes:
    tags: [python, automation]
    category: devops
    fallback_for_toolsets: [web]
    requires_toolsets: [terminal]
---

# Skill Title

## When to Use
Trigger conditions for this skill.

## Procedure
1. Step one
2. Step two

## Pitfalls
- Known failure modes and fixes

## Verification
How to confirm it worked.
```

#### 渐进式披露 (Progressive Disclosure)
- **Level 0**: skills_list() → 技能列表 (约3k tokens)
- **Level 1**: skill_view(name) → 完整内容 + 元数据
- **Level 2**: skill_view(name, path) → 特定参考文件

#### 条件激活
- **fallback_for_toolsets**: 当指定工具集不可用时显示
- **requires_toolsets**: 当指定工具集可用时显示
- **平台特定技能**: 限制到特定操作系统

#### 代理管理技能
- **技能创建**: 完成复杂任务(5+工具调用)后自动创建
- **技能更新**: 发现错误或找到工作路径时更新
- **技能删除**: 删除不再相关的技能

### 3. 学习循环 (Learning Loop)

#### 闭环学习系统
1. **经验收集**: 从任务执行中收集经验
2. **技能创建**: 将成功的工作流程转化为技能
3. **技能改进**: 在使用过程中优化技能
4. **知识持久化**: 推动自己保存重要知识
5. **跨会话学习**: 搜索过去对话，建立用户模型

#### 用户建模
- **Honcho辩证用户建模**: 兼容Honcho用户建模系统
- **跨会话连续性**: 建立对用户的深入理解
- **偏好学习**: 学习用户偏好和沟通风格

### 4. 部署架构

#### 多后端支持
- **本地后端**: 直接在本地机器运行
- **Docker后端**: 容器化部署
- **SSH后端**: 远程服务器部署
- **Daytona后端**: 服务器无部署，空闲时休眠
- **Singularity后端**: HPC环境部署
- **Modal后端**: 服务器无函数部署

#### 成本优化
- **服务器无持久化**: 空闲时成本几乎为零
- **按需唤醒**: 有请求时自动唤醒
- **资源优化**: 根据需求动态调整资源
